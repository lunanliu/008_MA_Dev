## 硬件架构与自审依据（先于RTL修改记录）

- 器件 xcvu11p-flgb2104-2-e；写侧150 MHz/6.667 ns，读侧125 MHz/8 ns。两核各自在NI节点的同源SCTL内，核内不跨域。
- 数据数组仍在LabVIEW，每个复样点为U32位模式，每次4点。编译参数 DDR_WIDTH_BITS 默认1280，必须是128的正整数倍；K=位宽/32，G=K/4。参数改变需要重编译并匹配Memory和数组类型。
- 运行时U32输入 ddr_capacity_words=C、sample_count=N、ddr_word_count=M；C>0、N>0、N mod 4=0、0<M<=C、M=ceil(N/K)。容量单位是DDR逻辑元素。Host不得上报大于实际分配的容量，RTL不能发现Host谎报的物理容量。N最多0xFFFFFFFC，不转换成有符号integer。
- 接受命令时锁存N/M/C；新增两个初始化状态：CONFIG_CALC计算64位M*K和N+K-1，CONFIG_CHECK检查区间。宽算术不串在持续握手路径上，无运行时除法器。初始化busy有效，非法参数不传输；暂停保留，取消/DDR失效优先于暂停。
- 组计数宽度由G推导，地址及完成计数保持32位，容量65536不是新上限。写侧单打包寄存器不变，接收和提交互斥，尾块补零。默认宽度下理想写服务N/4+M拍，150MHz约2.18GB/s上界，非持续速率证据。
- 读侧256块信用、min(128,M)预取阈值、当前块寄存器不变。stream_first/last与首/尾四点同时有效；N=4时同时为1。普通ready背压时保持数据、offset和首尾标志，成功交接后才推进。run_enable为独立暂停，取消/复位终止协议。
- read_done在最后四点被接收后保持，不等于Sync处理完成。DDR缺数据时valid拉低并计数，125MHz*4不能证明无空拍。
- 无新增整帧片上数组；单向规划H2T64KiB+预取40KiB+可选Sync16KiB，BRAM36暂留64块，URAM新增计划0。新增参数寄存器、比较器和首尾标志的LUT/FF暂不报精确值。动态数组选择及NI至CLIP路径尚需后续真实平台时序验证。

## 外部会话与CDC边界

Target VI为唯一控制者：EMPTY -> LOADING -> WRITE_DRAIN -> AVAILABLE -> REPLAYING -> AVAILABLE，异常转FAULT。完成装载产生有效段描述符，回放必须使用该快照；覆盖前撤销旧段有效标志。两命令同时到来拒绝，不排队。
new_session_safe为各域本地许可，不把异步busy直接交叉连接。跨域通过NI支持的命令/状态FIFO传原子描述符及完成消息。Host不得绕过会话状态机直接启动核。用户远端搭VI，本地交付状态表、消息格式与逐线连接说明，不宣称远端互斥已实现。
load_done只表示最后写请求已被接口接受。WRITE_DRAIN须依据NI实际Memory接口的写后读保证/完成机制释放许可，不使用任意固定等待。保证尚待平台核对；无法确认时不允许回放。复位不自动清NI FIFO和在途事务，清理后才恢复。
