# 四控制器透明回环：本轮增量设计

用户要求执行既定四段方案并提供零基础LabVIEW接入及测试预期。本轮不改已通过的四个RTL，只新增一条四角色相连的短行为测试和可复现的604点输入/期望值、完整教程。cwd及唯一写根保持Sync_DDR，原配对不恢复。

器件xcvu11p-flgb2104-2-e；四角色时钟150/125/150/150MHz，默认逻辑DDR宽1280bit，四点U32为一次交接。保持既有数据通路、寄存器边界、N/M/C快照、DDR信用256及已知长度会话，性能/物理约束引用DDR_FOUR_STAGE_DESIGN_ZH.md。无新增可综合硬件或资源声明。

模型链路：604个U32从Host FIFO进入Upload，实际写入输入Memory数组；Read以125MHz读取实际该数组，经有容量的125->150结果FIFO原样送到Capture，实际写入独立结果Memory；Download从该结果Memory取数，经过有限DMA FIFO及间歇Host读取后逐点比较原始输入。禁止读模型直接用期望函数代替两个实际Memory返回值。

输入u32[k]=0x12340000+k，k=0..603；低16位I=0..603，高16位Q=4660。N_in=N_out=604，M_in=M_out=16，最后DDR元素只有4点有效、36个U32为0；每段151组。回环预期604点、2416字节、逐项相等。它是运输链路测试向量，不是OFDM/SFO算法测试帧。

测试中临时让capture暂停，使有限结果FIFO回压125MHz播放；之后让Host停读，验证有限DMA反压下载。核对保持/恢复、两区地址0..15、尾部零、四段计数604、Host无丢失/重复/乱序。只一段数据和一条XSim，不重跑四个已成功角色测试。

双时钟FIFO为行为契约模型，模拟容量/原子四点及不同读写时钟，不包含NI Gray指针电路或亚稳态。Memory写后读可见性在模型中显式有条件释放，该条件不证明真实NI硬件具备同样完成信号。命令从TB按各域边沿提交，未验证真实Host寄存器CDC。真实Sync由透明直通替代，不修改其他Sync工程，不宣称同步算法通过。

复位模型清队列；真实硬件必须单独清理NI资源。顺序为输入装载并可读 -> capture已合法启动 -> 输入回放与结果捕获 -> 结果写后可读 -> 下载且Host持续消费 -> Host收齐。新会话许可仅在独占区域与旧事务清理完成时成立。

原生测试前冻结4RTL+新TB+工程实际源集、脚本、向量与工具哈希，由总管家签发新窗口。只create/必要xvhdl/xelab/一次roundtrip XSim，阶段180/300秒，整体600秒，单Vivado、general8/xelab16、预估4GiB峰值。无综合/实现/NI编译/板测/MATLAB。
