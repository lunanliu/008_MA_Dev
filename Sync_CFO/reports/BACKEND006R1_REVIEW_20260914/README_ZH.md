# BACKEND006R1 独立复核

74点CFO估计后端在本次行为验证范围内通过：输入为已提取的74个S38复数导频观测，RTL自己执行归一化、FFT256质量判断、相位拟合及最终选择。28组唯一输入、38次完整结果、10次取消、5次输入错误、14个新宽分母除法边界均精确。N/P节点分别3158/10266条，输出包含499位元数据、候选/最终频率和诊断字段，全位匹配。完整输出模式计数：MAIN30、DEGRADED1、INVALID5、ZERO2。

最长末输入至结果6792拍（按150MHz换算45.28微秒），完整事务8700拍，正常输出背压154拍；reset/abort各5次覆盖输入、归一化、FFT、除法和结果待收。源更新前/后/实际模拟均21成员，仅quality v1改为声明拆分v2；其余源、数学和测试不变。

实际执行包装原字节保持，native exit0，最终完整Job两查询为空；独立复核没有重复任何原生阶段。旧编译失败及日志保留。

该结论不包含从整帧S16波形提取这些导频的FFT2048前端，不证明整帧补偿、500MS/s持续吞吐、综合或150/500MHz物理时序通过。下一步是原算术一致的FFT2048、导频系数与求和前端；需要同时解决服务周期和存储端口安排，不能直接放大低吞吐FFT256结构。
