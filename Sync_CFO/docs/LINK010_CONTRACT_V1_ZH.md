# LINK010 原子观测值跨时钟与后端接入契约

日期：2026-09-15。状态：待原生行为验证；本文件不宣称 T11/T12/T13 整体通过。

## 输入、计算与输出

输入来自第二级 SFO 后 CFO 前端的窗口观测接口，每帧按 0–73 顺序提供 74 条记录。每条含 frame32、generation32、window7、z I/Q 各 S38、pilot_count10、FFT 饱和次数16及前端错误码4。正常 pilot_count 固定820。LINK010直接使用 FRONT009 已发布的真实 z，避免重复跑前端 FFT；另外三帧复用已验收 BACKEND006R1 向量覆盖降级、无效和零模式。仅第二至四帧增加饱和统计元数据，z及所有算法期望结果不变。

500MHz 输入域将整条记录封装为171位原子消息，通过官方 XPM async FIFO 送至150MHz估计域。每次只允许一帧在途。后端保持冻结的74点相位拟合、256点FFT质量检测与模式选择。输出完整499位后端记录，另带 link_error4、front_error4、累计FFT饱和数23，共530位。饱和元数据不参与当前算法判决。

FIFO为distributed、深度16、FWFT、2级跨域同步；FWFT有效存储可能包含2条输出级，因此验证允许计数至18，不能将行为计数误作16条物理RAM。复位/取消共源异步置位、各域4级同步释放。写域等待wr_rst_busy结束，读域等待rd_rst_busy结束。慢域结果握手后toggle信用经2级同步送回快域，才接纳下一帧。

## 错误与恢复

link_error优先级：前端错误→4；pilot_count不是820→5；window>=74→3；中途frame/generation变化→1；window不等于期望顺序→2；任一z为S38最小值→6。错误消息沿FIFO排队，保留本帧首次锁定frame/generation及错误包实际window。消费错误时同时abort后端两个分支；错误结果只保留frame/generation，499位后端其余字段归零，独立link_error与front_error指明原因。前缀及错误包的FFT饱和数均计入诊断。

错误输入一经握手即终止当前帧。上游必须丢弃该帧剩余窗口；错误结果握手后从下一帧window0恢复。内部backend非零error属于异常实现/一致性故障：交付一次错误记录后不返信用，须整体reset/abort恢复；它与可自动恢复的link_error不同。全局reset/abort取消所有在途记录，后续不得交付旧结果。

## 固定验证范围

四个正常向量初跑：真实FRONT009全74窗口按已测15448快时钟周期间隔送入，其余三帧突发送入。八次取消（reset、abort各四次），位置为FIFO有积压、后端只收13条、后端FFT计算中、结果等待接收；每次完整恢复一帧。十类错误：frame、generation、漏窗口、首次窗口非0、window74、pilot_count819、前端错误1/2/3、S38MIN；每次错误后无全局复位完整恢复一帧。

应完成22帧、8次丢弃、10次错误，并真实退休32个正常/错误结果。W输入2056条，R消费数量按取消前已消费前缀逐条核对。逐条验证所有W/R记录、全部530位结果和真实m_valid&&m_ready握手；输出保持5–8个慢周期并检查握手边界。突发21帧均须触发FIFO full和输入背压；真实前端节奏帧不得产生输入背压。不得溢出、下溢、丢失、重复、乱序或跨帧。

计时从实际接受事件计算：最后一条后端输入至结果有效≤7800慢周期；首条输入至结果有效，突发≤45000快周期，真实节奏≤1170000快周期。仿真快时钟2ns、慢时钟6.666ns、起始相位0.417ns；初始复位200.231ns，后续异步取消50.117ns。上述为行为门限，不是布局布线后频率与CDC认证。
