# T10 的 MATLAB 与定点参考：从哪里来、怎样使用

本目录整理的是 T10_FULL023 实际使用的参考来源，目的在于让开发者看懂、追溯并进一步维护独立工程。它不是新的实验结果。本次只复制、适配路径和进行静态校验，没有启动 MATLAB、Python 数值模型、Vivado 或 RTL 仿真。

**这里没有一个“整条 T10 的 MATLAB bit-true 顶层”。** 当前依据由 MATLAB 的信号生成及整数重采样、保存的 T06 RTL 估计结果、Python 的 T09 定点运算、AMD 官方 FFT 定点模型，以及已有 RTL 参考输出共同组成。bit-true 指尽量逐位复现有限字长运算，不等于使用 MATLAB 浮点计算一个看起来相同的公式。

## 1. 先从这两个入口看起

在 MATLAB 命令窗口执行以下命令，只添加本工程路径并查看已保存 MAT 文件中的变量清单，不重新生成波形：

```matlab
cd('D:/008_MA_Dev/matlab');
p = setup_t10_reference();
info = inspect_full023_reference();
```

`setup_t10_reference.m` 根据自身位置寻找文件。以后整个工程换盘或改目录时，该函数内部不用改绝对路径；上面的 `cd` 相应调整即可。它返回 `p.package`、`p.t09Fixed`、`p.data` 和建议的新输出目录 `p.output`，不创建实验输出，不启动旧监管进程。建议使用干净 MATLAB 会话，避免先前加入的旧工程同名函数遮蔽这里的函数；可用 `which t07_fixed_arithmetic_window -all` 检查解析位置。

## 3. 五种对象不要混为一谈

| 对象 | 回答的问题 | 本次保存或入口 |
|---|---|---|
| 原始无偏差波形 | 理想发射端本来发了什么？ | T02 前导/导频实物、帧配置、随机种子与 `bistatic_generate_continuous_waveform.m`；未另存一份新生成的无偏差全波形 MAT |
| 高精度施加偏差后的波形 | 接收端采样时钟不准时，应当看到什么？ | `bistatic_apply_cp_ofdm_channel.m` 和相关 `common/` 函数；实际 I16 量化输入保存在 `raw_input.mat` |
| MATLAB 有限字长重采样 | FIR/Farrow 电路的舍入和饱和会带来什么？ | `helpers/t07_fixed_arithmetic_window.m`；两遍保存输出为 `first_resampled.mat` 和 `second_z2.mat` |
| T09 定点估计参考 | 第二次 SFO 估计在所选定点 FFT/运算下应得到多少？ | `T09_FIXED007/t09_fixed007.py`，调用 `t09_xfft_cmodel007.py` 和官方 DLL；FULL023 使用已有 case006 的 `pow2_headroom` 分支 |
| 实际 RTL | 寄存器、握手、缓存和有限字长运算组合后，硬件描述是否输出正确数据？ | 新工程 `rtl/`、`ip/`、`sim/`；不能用 MATLAB 通过代替 RTL 验收 |

SFO 是 Sampling Frequency Offset，即收发两端**采样频率偏差**。CFO 是 Carrier Frequency Offset，即**载波频率偏差**，表现为复数信号相位持续旋转。FFT 是快速傅里叶变换，用来把一个时域符号转换成各个子载波。FIR 是有限冲激响应滤波器；Farrow 是根据所需小数采样位置计算插值结果的一种结构。

## 4. FULL023 的实际输入是什么

以下均来自已复制的原始配置和 `full023_fixture_provenance.json`，不是本轮重新测量。

| 项目 | 已冻结值 |
|---|---:|
| 名义复采样率 | 500 MS/s，即每秒 5 亿个复数样本 |
| 每符号 FFT / 循环前缀 | 2048 / 512 样本 |
| 每帧组成 | 10 个前导符号 + 512 个载荷符号，共 522 个符号 |
| 名义帧长度 / 时长 | 1,336,320 样本 / 2.67264 ms |
| 本用例帧编号 / 生成编号 | 6001 / 1 |
| 人为施加 SFO | −150 ppm；ppm 表示百万分之一 |
| 人为施加载波偏差 / 提供的粗 CFO | +100,000 Hz |
| 精定时起点 | 0 |
| 信道 | 无噪声、单径 |
| 连续波形基础随机种子 | 90401 |
| 第一遍前输入 `raw` | 1,336,860 样本，绝对坐标 −172 到 N+367 |
| 第一遍输出 `y1` | 1,336,392 样本，绝对坐标 −36 到 N+35 |
| 第二遍输出 `y2` | 1,336,320 样本，绝对坐标 0 到 N−1 |
| RTL 数据接口 | 每拍 4 个复数样本，每个 I/Q 分量有符号 16 位，共 128 位 |

这里 N=1,336,320。帧两侧的额外样本给有限长度滤波器提供邻域，避免把缺失样本误当成零。来源描述保留了相邻真实符号/帧的归属；这不是把无关帧任意拼进去。信号时间坐标与 MATLAB 的数组下标也不是一回事：负时间坐标仍存放在从 1 开始的合法数组位置。

原浮点接收信号先乘 `integer_per_unit=263403.20193827286`，执行 I16 舍入/饱和，再在保存的 MATLAB `raw` 中除以 32768 表达。不能把这个缩放系数当成所有波形均固定使用的 I16 满量程比例。实际缩放和来源以本用例 `input_identity.json`、`source_descriptor.json` 和上游 context 为准。

源 MAT 的变量和完整形状可用只读入口查看；不要仅根据文件名猜测。这里既保留原字节文件，也保留其原始哈希。

## 5. 高精度 SFO 注入是怎样计算的

信号源把发射采样率设为 `fsTx`，把接收采样率设为：

```text
fsRx = fsTx × (1 + sfo_ppm × 10^−6)
sourceStep = fsTx / fsRx
第 n 个接收样本在发射波形中的坐标 = n × sourceStep − 公共延迟
```

所以正 SFO 表示接收时钟更快，每取得一个接收样本，在原发射时间轴上前进的距离略小；负 SFO 相反。载波相位按真实接收采样时间 `n/fsRx` 计算。

原发射波形由 OFDM 子载波定义。当前高精度方法先生成 128 倍的傅里叶插值网格，再做 8 点插值；靠近物理符号交界、不能安全使用这些插值节点的位置，改用该位置所属符号的直接傅里叶计算。代码标识为 `interpft_l128_barycentric8_boundary_direct_fourier`。它维护循环前缀和相邻符号的物理归属，不采用通用 PCHIP 插值回退。

这是**生成可信接收输入的方法**。RTL 为实时处理使用的是另一个实现：两级 2 倍升采样、Farrow 小数位置插值、两级 2 倍降采样。二者职责不同，不应该要求信号源也机械照抄 RTL，否则同一个实现错误可能同时进入被测对象与参考。

## 6. 两遍校正及 T06/T08/T09 的来源

`CLOSED002_rev02/t09_closed002_rev02.m` 是原 MATLAB 研究入口。它从冻结的 T02 实物生成连续波形，施加偏差并量化，读取 `upstream/C01…C03/service_result.csv` 中已经得到的**真实 T06 RTL 第一遍 SFO 估计**，完成第一遍整数重采样，再提取导频节点并做 T09 浮点估计和第二遍整数重采样。

因此该入口具备信号和校正算法来源，但它不会重新执行 T06 RTL，也不会从头重新得到粗 CFO 或精定时。T08 所需的导频契约/节点关系由配置、生成与提取函数、保存的 `first_nodes.mat` 和定点包 `pilot_contract.mat` 保留。它不是重新运行 T08 RTL 的入口。

整数重采样配置为 14 位系数、16 位数据、8 位小数位置、28 位步长小数。两个半带 FIR 由 `firhalfband(46,fp)` 与 `firhalfband(14,fp/2)` 构造，分别有 47 和 15 个抽头；插值采用三次 Farrow。关键缩位处执行“四舍六入、五时取偶数”的最近偶数舍入及饱和，避免简单截断的系统偏差。

`second_z2.mat` 对应原研究的 2 倍补零分支；未把研究用的另一份 `second_z4.mat` 作为当前 FULL023 参考复制进来。保存的参考输出与实际定点估计的预期值是两类证据，不能把 T09 浮点研究入口直接称为 T09 定点黄金模型。

FULL023 的预期估计记录如下（Q18 表示 ppm 数值再乘 2^18 保存成整数，Q28 步长同理）：

| 估计 | 预期 ppm | ppm 的 Q18 整数 | Q28 重采样步长 |
|---|---:|---:|---:|
| 第一遍 SFO | −149.93223190307617 | −39,303,835 | 268,395,209 |
| 第二遍 SFO，`pow2_headroom` 分支 | −0.049381256103515625 | −12,945 | 268,435,443 |

这些是检验 RTL 结果的预期记录，**不是把正确答案直接灌给 DUT（被测 RTL）**。原 FULL023 使用真实 T06 和真实 T09。其粗 CFO、精定时和帧描述符来自已保存的上游边界信息，没有把整个前端捕获链重新集成执行。

本迁移范围止于第二次 SFO 重采样；全帧 CFO 和后续 Residual CFO（剩余载波偏差）补偿不属于本参考集合。

## 8. 清单能否继续校验，哪些验收不能据此宣布通过

- `CLOSED002_rev02/manifest.json` 原字节保留。它的 `files[].path` 是包内相对路径，整个快照移动后仍可逐项校验。本轮已通过这项静态校验。
- `T09_FIXED007/manifest.json` 因上述 Python 路径适配更新了该脚本的本地哈希，其他内容保持来源；本轮本地包逐项校验通过。原始 manifest 单独保存在 `matlab/provenance/FIXED007_ORIGINAL_MANIFEST.json`，它自然不会匹配已适配的脚本，不能谎称原包全部逐字节不变。
- manifest 中 `source_path`、原任务书和 provenance 中的旧绝对路径是来源标签，不是本地执行路径。查找新文件应使用本次 CSV 的 `destination_relative`。
- 本次 CSV 同时记录原始和目的哈希；除了明确记录的路径适配及相应清单变化，来源复制件逐字节一致。新入口和本文档注明为新生成文件。
- FULL023 使用保存参考进行逐分量误差和 FFT 窗口误差比较。其误差是“RTL 与冻结参考”的差异；计算时不做额外增益/相位拟合。它不是无线收发 EVM，也不直接等于“最终输出与无偏差原始理想波形”的误差。
- 已保存来源不等于新顶层已验收，不证明新器件/新约束下时序通过，不证明连续多帧持续吞吐，也不证明板上通过。完整工程的最新状态应查看根目录项目说明及 RTL/综合证据；原 FULL023 的 `T10_PASS=false` 和延期边界仍保留。

本次保留的约 55 MB 主要是完整帧参考 MAT、必要 T02 实物和官方 FFT 模型。没有把旧工程所有实验结果、缓存或 MEM 数据整库复制过来。
