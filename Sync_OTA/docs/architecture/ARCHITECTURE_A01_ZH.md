# Sync OTA 首版架构与存储合同 A01

2026-09-16。范围已获用户授权，持续实现到真实整链核心和交付。本文冻结首版有限长度离线模式及OTA001新增边界；整链连接、正式SFO参数发布、核心综合仍在开发，不能称已通过。

## 处理与调度

1. NI Target提供125/150/500MHz三个连续时钟、DDR物理控制器和本合同的事务服务。RTL不另建DDR PHY，不争用引脚。clk125处理控制/Host/DDR/前端，clk150处理SFO重采样及两次CFO旋转，clk500处理FFT服务。500MS/s是数学采样率，不是500MHz SCTL要求。复位等待平台时钟稳定后释放，各域同步释放；DDR会话复位必须同时清空NI侧在途事务。
2. 先将用户有限采样文件完整写入并seal。每次写必须收到确认才计入committed_words。检测在封存后从绝对位置0回放；accepted_samples只数被前端实际接收的采样，不数周期。完整输入保留，因此不依赖检测延迟保证前导存活。最低前保护为nominal_abs>=172，尾部必须覆盖nominal_abs+1336687；缺保护范围报错，不补零伪造样本。首版每次只处理一个检测帧，成功/失败后由新会话继续。
3. 前端实际288位记录转换为SFO三条记录并锁定frame/generation。nominal_abs=fine_abs向下对齐4，local_TO=fine_abs-nominal_abs，raw回放绝对起点nominal_abs-172，长度1336860样本（334215拍）。SFO tap坐标为-172+4*b，与DDR地址分开。
4. 首先回放全部raw到SFO内部raw环和既有训练观察缓存，之后才释放三条描述符到估计器。SFO原始环393216拍大于334215拍；训练窗口5272..25959由专有捕获保存直到lease_release。这样DDR慢响应不占65024周期的算法服务预算。适配器三路valid可分别保持；调度必须将实际输出ready门控到raw装载完成，不能预先消耗。
5. 真实初次SFO估计包含局部粗CFO训练旋转→第一次重采样→74观测残余SFO估计→第二次重采样。保留已验证的全部内部raw/R1/output存储及释放协议。
6. raw外存最后一拍已被SFO接收、DDR读信用为零后，外部区域才能释放并以新物理租约用于粗CFO输出。逻辑frame/generation在这一步保持，DDR事务generation另行增长。SFO2数据进入第一套CFO相位旋转，各样本独立RNE/S16饱和后写回该DDR区。等待外存租约转换时通过ready背压SFO输出，不能删掉output ring。
7. 粗补偿整帧封存后，按25984+17920*m起点回读74个2048点窗口，m=0..73，逐个送真实FFT2048/导频前端（S16左移6到S26/F21），真实74点相位/FFT256后端给残余CFO。可串行等待每窗完成，不追求流式500MS/s。LINK010R1_v2源仅作为新任务修订基础，复位观测门仍须本任务实证关闭。
8. 锁定残余结果并配置第二套坐标控制/旋转核，重读整帧，执行第二次独立RNE/S16饱和后输出。INVALID保持无效状态，不能按零频补偿数据当成功。最终last实际握手后释放外存。两次旋转不可合并。

## 可接线DDR事务口（已实现ota_frame_store）

全部信号clk125：cmd_valid/ready、cmd_write、cmd_address[63:0]（128位字地址）、cmd_tag[63:0]、cmd_data[127:0]；rsp_valid/ready、rsp_tag、rsp_data、rsp_error。一次cmd握手消费唯一信用，NI必须在至少一个后续上升沿返回且仅返回一次rsp；写响应表示写入完成且后续读可见。读响应带完整128位。响应和输出各支持背压，valid保持时负载不得改变。没有突发、隐式信用或物理DDR时序假设。

cmd_tag={物理租约generation32,serial32}。物理租约每次start增加；frame/generation是独立逻辑身份，RAW→COARSE换租约不能改逻辑身份。有限作业事务总数必须小于2^32；管理器限制容量/回放次数保证。新start仅空闲接受；seal是写确认栅栏；replay_first/count超范围拒绝；release只有已封存无读者时生效；cancel停止新请求并等待已接受请求的正确tag响应排空。错误tag响应不退信用。NI不返回已接受响应时只能由用户执行协调的全系统复位，不能强行新开会话覆盖旧数据。rst的前提是NI端同样完成排空/复位，不支持单侧运行中硬复位。

每条请求最少经历请求/等待/响应/输出状态，DDR峰值接口2GB/s不代表实际吞吐。若响应延迟L个125MHz周期，保守调度用每读拍至少L+3周期计，写拍至少L+2周期；还要加NI服务、背压和CDC。带宽预算：原始捕获16C字节、检测最多16C、SFO回放5347440、粗写5345280、74窗读取606208、最终回放5345280字节。数据/描述符/FIFO另计。首版是有限离线方案，不承诺连续500MS/s；4×150MHz只为算术口600MS/s峰值。

## 正式描述符与参数发布

前端位域：epoch[287:256]、frame_id[255:224]、candidate[223:192]、coarse_abs[191:128]、fine_abs[127:64]、signed CFO integer Hz[63:32]、quality[31:16]、status[15:0]。FE epoch只验证对应扫描会话；capture管理器生成逻辑generation，禁止用candidate或epoch直接冒充bank generation。

SFO188={frame32,generation32,raw_first_word64=0,nominal_relative32=0,q0Q28=0}；CFO96={signed integer Hz32,quality16,0x2800,frame32}；fine96={local_TO32,quality16,0x3800,frame32}。质量字段保留前端fine质量供溯源，不将其称为独立CFO质量测量。status必须为0x3800；Hz转F8必须范围检查，允许[-8388607,+8388607]，之后左移8。raw第一拍来自nominal_abs-172，环内word序号0，不是DDR物理地址。

CFO坐标的原点采用已选择nominal_abs为局部零点：raw_origin=local_TO+q0。保留nominal_abs64用于绝对溯源，不截断到54位Q28。qRaw(n)=raw_origin+(step1/2^28)*(step2/2^28)*n；连续流的绝对常相位参考不由粗频估计确定，比较数据须用相同局部相位原点/明确常相位对齐口径，不能要求未知信道常相位自动归零。

下一实现必须从两个resampler实际descriptor成功握手增加正式发布端口：frame/generation、实际step、phase、error；取自d_step/d_phase被算法装载的同一握手，不读diagnostic_step/debug总线。E1发布后按bank/frame/gen保存；E2发布时严格匹配并原子合成CFO上下文{frame32,gen32,step1Q28,step2Q28,originS54Q28,coarseS32F8}共214位。CFO接受上下文前禁止消费该帧SFO2首拍；上下文ready停顿必须保持稳定，不通过名义ppm重算/参考真值代替。该发布修改尚未实施，不能标已闭合。

## CDC及首错

将完整数据记录与frame/gen同过异步FIFO，配置同样原子化；单比特busy/完成用握手同步，不逐位同步宽总线。新DDR边界为125MHz，CFO输入/输出150MHz通过独立FIFO；稀疏窗数据125→500，观测500→150。复位异步停止接口、同步释放；XPM_FIFO的rst必须同步于写时钟，双方busy及回执完成后才能接收新记录。旧SFO CDC继续核查，不能因为已有行为通过就跳过实际rst语义。首错锁存stage/code/身份，禁止继续输出成功标志。
