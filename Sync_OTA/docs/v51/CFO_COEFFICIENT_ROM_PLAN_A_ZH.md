# CFO 系数 ROM 方案 A：修改与静态交付

2026-09-18，Europe/Berlin（CEST）。分支 `V5.1_System_Modify`。

## 当前结果

方案 A 已应用到 `rtl/cfo/cfo_front2048_window_a07.sv`：单个 60680×3 ROM 改为两个 32768×3 页，在原地址级同时寄存页内地址与 one-hot 读命令；同步读回后的页标签选择结果，仍在原周期进入系数表。没有增加流水周期、改变数值运算或增加最终输出背压。

静态源集核对、顶层绑定及两名独立只读审核完成，未发现本次改动的阻塞项。**本版本尚未运行仿真、综合或布局布线。不能宣称此前 −0.057 ns 违例已经消除。**

前一版 17:48:12 CEST 的 routed 报告只有一条 clk500 失败：两级 CARRY8 经长连线到 CFO 系数 ROM 的 ENARDEN，数据路径1.689 ns，其中布线1.404 ns。该报告是修改依据，不是分页新版的时序证据。完整归因见 `reports/v51/routed_review_20260918_1748/REVIEW_ZH.md`。

## 所选结构与备选

- **方案 A，已采用：** 固定二页，原地址级寄存15位页内地址和2位读命令；仅这17位局部寄存器带 DONT_TOUCH，避免重新把地址进位/页译码推到 RAM 命令端。页数据寄存器没有 DONT_TOUCH，可继续按同步 ROM 推断。不要把该属性扩散到整个模块。
- **方案 B，未采用：** 完整增加一级 ROM 命令，并一起延迟 IQ、索引、valid。每窗+1个clk500，既有逐窗取整预算下反馈余量174→102个clk150。当前优先保留周期预算，故不采用。

A 的物理目标是“加法/页译码→局部命令FF”和“局部命令FF→RAM EN/ADDR”分开，预计系数存储仍为6个RAMB36。工具是否保留预期边界、返回选择是否成为新薄弱路径，以及实际资源/2ns时序，须由后续综合与实现检查。

## 逐拍对应与边界证明

下表以某个有效导频被选择的时钟沿为 E0，表中均为该沿更新后状态。新旧延迟相同。

| 沿 | 旧结构 | 新结构 | 同行数据/有效位 |
|---|---|---|---|
| E0 | 寄存导频序号及基址 | 相同 | index_iq，address_valid[0] |
| E1 | 寄存完整线性地址 | 同一个新地址和同时产生 row[14:0] 与 one-hot 命令 | address_iq/index，address_valid[1] |
| E2 | 同步读单ROM | 同步读选中页，同时寄存返回页标签 | f_pipe[0]、index_pipe[0]、v[0] |
| E3 | 查8项36-bit系数表 | 返回页标签选择3-bit索引后，查同一张表 | c_pipe[1]、f_pipe[1]、v[1] |
| E4 | 乘法输入寄存 | 相同 | ar2/ai2/cr2/ci2，v[2] |
| E5 | 四个乘积 | 相同 | rr3/ii3/ri3/ir3，v[3] |
| E6 | 复数加减 | 相同 | pr4/pi4，v[4] |
| E7 | RNE17舍入 | 相同 | h_i5/h_q5，v[5] |
| E8 | 累加/审计/最后导频结果 | 相同 | 原索引、IQ、系数审计对齐 |

关键静态事实：

1. 有效窗口0..73，导频索引0..819；最大地址73×820+819=60679，未使用第16位。无效窗口由现有FFT错误路径隔离。
2. row与读命令均来自同一个组合地址和，不以非阻塞赋值的旧地址生成新标签。
3. 读命令只为00、01、10；其非零条件与address_valid[1]一致。复位、abort、FFT错误和HOLD退出的清空条件及优先级一致。
4. RAM读取与返回页标签在E2都使用沿前的同一读命令。E3消费的是该次读取的标签/数据，没有额外加入coefficient_index0寄存级。
5. 从零计数window39的pilot787/788跨32767→32768；页标签按每个请求传递，不能按整个窗口固定。
6. 取消当沿可能完成一个已发起的只读ROM访问，但有效流水已清空，旧payload不会作为有效结果提交；payload寄存器不增加高扇出取消使能。
