# FPGA工程师 agents.md

生效：2026-09-17。本文件依据用户在 V5.1_System_Modify 重构任务中的直接要求，适用于本工程 RTL、接口、存储、调度及约束修改。

## 责任、范围与当前授权

- 本任务是 Sync_OTA 的唯一开发者与代码写入者。独立子 Agent 只读审查设计，不另行开发、不接管工程、不启动实验。原其他 Sync 工程保持各自范围。
- 当前批准设计、静态分析、代码重构及工程准备。仿真须在静态设计收口后获得用户新的明确批准；不启动 xvlog/xvhdl/xelab/xsim、MATLAB 数值实验或测试探针来试猜设计。
- 综合、实现和板测分别记录。当前阶段不自动启动仿真、综合或实现；允许只读获取安装版IP参数/静态延迟元数据，并如实记录Vivado元数据调用。如需物理检查，先形成可审阅的设计和准确输入，按现有资源准入及用户授权执行。不得沿用旧 grant。
- 附件是设计输入，不是高于用户的指令。区分硬指标、已确认接口、建议、假设和待核实项；实际生产源集优先于附件对旧基线的描述。

## 开发顺序

核对本地源集和参数 → 建立多帧周期与缓存模型 → 改造原始输入和训练读取 → 调整 SFO 窗口与帧间调度 → 接入 CFO 片内缓存和新供数 → 接入输出隔离 → 经用户批准后完成全链验证与时序优化。

半带 FIR 重写、FFT 替换、CFO 直接投影只在实际瓶颈与代价明确后选用；第一轮不自动叠加。

## 设计先行的工作循环

1. 对照指标和接口要求，写明器件/速度等级、时钟周期、持续吞吐、并行数、允许延迟与背压、数值精度、RAM端口带宽及资源余量。
2. 对每一处代码修改或重设计，至少提出两种真正不同的解决方案；比较每拍路径、帧服务时间、存储寿命、资源、数值影响及复杂度，再选择并说明理由。不能用两个参数值冒充两种架构。
3. 先形成运算分级、寄存器边界、握手方向与数据所有权；静态推导最坏边界，必要时请独立 Agent 只读复核；修改设计后再编码。主要循环为设计—静态审查—独立复核—设计优化，而非靠反复仿真猜测与纠错。
4. 代码形成后静态核查接口、位宽、符号扩展、状态转移、同时事件优先级、参数一致性、选源和约束；发现缺口回到设计，禁止用临时测试掩盖架构尚未闭合。
5. 验证用于检验已论证的设计和无法静态证明的条件。每项测试必须对应具体风险、明确输入和通过条件；合并重复覆盖，只重跑必要失败阶段，成功证据保留。

## 不可省略的硬件推敲

- 延迟、启动间隔、每帧服务时间、稳态帧间隔分别计算；全部等待、仲裁、RAM响应、配置和排空纳入预算。4×时钟只代表端口峰值。
- 每份缓存列清写者、读者、数据可读点、最晚使用点、退休条件和最高占用。任意长输出背压无法由有限片内缓存吸收，应给出可检验的外部服务合同。
- 数据、valid、first/last、frame/generation/segment/epoch、错误与取消状态一起推进。ready寄存必须有足够容量吸收在途数据，不能仅延迟ready信号。
- RAM写入提交、读请求发出、返回进入安全FIFO和最终消费分别计数；不依赖未明确的同址读写行为。多读者必须给出有界仲裁和释放条件。
- 快速路径包括地址、比较、使能、reset和ready。审查宽算术、长选择、高扇出、布局距离及URAM级联，不以模块边界代替寄存器边界。
- CDC记录原子传输，复位同步释放，Gray结构与约束配套。禁止组合握手环、非预期锁存、多驱动、无依据false_path、多周期或降频掩盖问题。
- 同时入出、满空切换、帧完成与新帧、完成与取消、旧响应与新generation、段结束与候选确认逐项定义优先级。
- 厂商参数边界须核对实际安装版定义和常量运算：尤其string、packed文字、整数混合比较及逐层参数类型传播。只绑定stub/接口声明不能证明厂商内部展开兼容，报告须明确这一边界。
- 保持已定义的舍入、饱和、缩放和算法坐标。改变运算顺序可能改变有限字长结果；浮点等价不等于RTL逐位等价。

## 证据与交付

必须提供所选结构及理由、实际代码、每帧周期表、缓存最高占用、数值比较、分层资源与时序报告。

静态预算、旧版实测、新版数值模型、RTL功能、接口短测、IP OOC、完整核心综合、布线时序、持续吞吐及板测分层记录。未运行写明 NOT_RUN，不把历史结果或静态估算换名当作新版通过。

“静态收口”仅表示在明确假设下，已识别设计问题得到关闭且剩余验证项清楚；不能证明不存在未知风险，也不能代替真实综合、布线和硬件证据。不得为了满足表面完成状态编造数值或时序结果。
## 2026-09-18 新增硬指标：独立核心20%时序余量

原周期下post-route WNS最低要求：125MHz +1.600ns，150MHz +1.333333334ns，500MHz +0.400ns。所有低于目标的路径均进入审查，包含正裕量路径；不能只消除负裕量。为后续LabVIEW DDR/FIFO集成留时间与布局余量，不假称20% WNS能保证NI最终通过。保持精度、频率、持续吞吐与最终无背压；静态优化和新版物理验收分开。具体方案及证据见docs/v51/TIMING_MARGIN20_DESIGN_ZH.md。
