# CFO FFT2048 单元合同 V1

2026-09-14。属于用户已恢复的 T11/CFO RTL 开发；Astra 审查，原配对 Luna 执行。

## 输入和算术

- 2048 点自然顺序 S26 复数输入。真实前端的 S16/F15 粗 CFO 旋转结果乘 64，表示 S26/F21。
- frame/generation 各 32 位、window 7 位（0–73）、index 11 位、last。每帧窗口内部元数据固定，索引从 0 到 2047。
- 输入存储时做 11 位 bit reversal。11 级 radix-2 DIT；每级 1024 个蝶形。
- twiddle 为 S18/F17，RNE 量化并饱和；+1 的编码是 131071。复乘先精确加减、RNE 除 2^17，再对蝶形的加减结果 RNE 除 2 并饱和 S26。不能提前截断复乘。
- 26×18 乘积 44 位，复乘加减 45 位，RNE 后 28 位，蝶形加减 29 位，除 2 后 28 位。饱和计数为 16 位；每个蝶形最多四个分量饱和。
- 输出自然顺序 2048 点，附原始元数据、累计饱和数和 error。m_valid && !m_ready 时整个输出包稳定。

## 流水与存储

bank = 地址 11 位的 XOR，row = 地址低 10 位。两个存储体各 1024×52 位；同一蝶形的两个地址只差一位，必在不同 bank。每个 bank 每周期最多一次读、一次写。同一级蝶形地址不重叠，写回和随后发出的读不存在地址冲突。

一次发出蝶形到写回相隔 7 拍：同步 RAM 读 → RAM 输出寄存 → 操作数寄存 → 四乘法 → 复乘加减 → RNE → 蝶形加减 → RNE/饱和写回。每一级发出 1024 次，排空 7 拍；相邻级最后与首次写回间隔 8 拍。

输出有同步读、附加 RAM 输出寄存和输出寄存；按统一使能停住全部输出预取管线，连续接收时输出间隔一拍。

计划工作时钟 500 MHz。11×1031=11341 计算拍，2048 输入及2048输出加管线开销，理想服务预算约15440拍（30.88 us）。TB另有起始调度开销，以扣除明确输入空拍和输出背压后的服务周期≤15550为门槛；首输出距末输入≤11450，测试总周期≤19000。该预算小于500 MS/s时窗口间隔35.84 us，**但不证明500 MHz时序，也不证明600 MS/s突发、CDC、缓冲深度或整帧无丢点**。

## 错误与清除

错误优先级：window≥74返回3；非首点frame/generation/window变化返回1；index或last不符返回2。错误包保留首点元数据（首点非法window则保留非法值），index0、last1、IQ0、饱和0。消费错误包后重新收集窗口。

同步reset/abort清除状态、有效位和标签。不清RAM；下一个完整2048点加载会覆盖全部存储。未完成输入、蝶形计算或输出都可丢弃；不能泄漏旧结果。
