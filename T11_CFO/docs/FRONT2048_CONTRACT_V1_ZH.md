# CFO 窗口前端合同 V1

2026-09-14。输入是已经按整帧全局坐标完成粗CFO旋转的窗口。输出为送给后续74点残余CFO估计器的一项复数观测z。本单元不接受原始未旋转的输入作为等价参考。

## 完整数据路径

S26/F21自然顺序2048点输入 → 已验收cfo_fft2048_core → 选择820个导频频点 → 乘对应复数系数 → 求和得到一个S38/F21复数z。

FFT核原字节复用FFT008，不更改其RNE/逐级缩放/饱和。输入和FFT时钟计划500 MHz。每个窗口输入元数据frame32/generation32/window7/index11/last沿用FFT合同，window允许0–73，不要求此单元跨窗口保存帧状态。

只保留自然FFT bin 2,4,...,820及1228,1230,...,2046，对应有符号k=2,4,...,820,-820,-818,...,-2。前半导频index=bin/2−1，后半index=bin/2−204。两半各410点，合计820。

系数使用已发布pilot_coeff_codes，已经包含conj(P)和128点LoS对齐相位。19案例的74×820系数矩阵完全一致，共8个S18/F17复数值。保存60680×3位索引加8×36位表，所有位无损还原。净系数数据从2184480位降为182328位；这不是实际BRAM数量或布局结论。

## 运算和流水

每个选中FFT点记作(a,b)，系数(cr,ci)：H_I=RNE((a*cr−b*ci)/2^17)，H_Q=RNE((a*ci+b*cr)/2^17)，再求820项复数和。

乘积44位，复乘加减45位，RNE后S28。对完整合法S26/S18输入，复乘归一化的绝对值≤2^26，必在S28内，故MATLAB规定的S28饱和在该输入范围内恒等；没有省略可能发生的溢出。820项累加用S38，无中途量化，和的绝对值<2^37。

从选中FFT握手到H累加相隔6拍：索引ROM读 → 8值系数表解码 → 操作数寄存 → 四乘法 → 复乘加减 → RNE → S38累加。数据、系数、pilot index逐级对齐。每2拍一个有效导频；两段交界从bin820到1228间隔408拍。

需同时完成最后FFT输出与最后H求和才公布z。结果177位：frame32/generation32/window7/z_I38/z_Q38/pilot_count10/fft_saturations16/error4。输出阻塞时完整结果保持，同时阻止接收下个窗口。消费后重新开放输入。

## 取消与异常

同步reset/abort同时清FFT和本地有效位、累计和、计数及待发布结果，保持RAM无复位。新窗口完整输入覆盖旧RAM。验证覆盖输入中、FFT计算中、H流水/累加中、z保持中四个位置，各reset/abort及新事务恢复。

FFT错误原样传播：window范围3、窗口内frame/generation/window变化1、index/last错误2。错误结果保留FFT锁定元数据，z/pilot_count/saturations清零。首点非法window仍保留该值。输出错误包后恢复输入。

## 参考和时序边界

整数参考验证82个发布窗口（case001全部74窗，case003/081各0、1、36、73窗）：67240个复数FFT点、67240个复乘结果、82个z逐点一致；另加8个完整S26整数边界，共90唯一窗口。

case001连续测试74个窗口的frame/generation相同、window依次0–73，覆盖全部60680个系数地址。输入仍是已抽取的窗口序列，并非1336320点连续整帧波形。

TB门槛：末输入到z有效≤13500拍；扣除已记录输入空拍/输出背压后的服务周期≤15600拍；含本次人工空拍总周期≤19000拍。延续FFT008测得15441拍附近预算，并为乘法求和尾部增加流水。

本阶段尚无500MHz物理时序/资源报告；不证明600MS/s突发、全帧无丢点、CDC、帧缓存、估计后端连接或两次全帧旋转。只有完成这些环节才可声称整链吞吐。
