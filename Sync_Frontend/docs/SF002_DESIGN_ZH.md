# SF002 连续捕获实现冻结说明

本次新增sync_beat_ram、sync_rolling_metric、sync_continuous_detector、sync_frontend_top。原有31个迁入RTL/TB保持原样；SF001_files.csv仍可验证。新增滚动累加器复用35/34→43/42位加减和溢出检查，去掉512-beat有限窗控制。已有4lane复乘、度量阈值、粗/精估计及官方IP仍复用。

候选由连续1024延迟/1024滑窗产生。第一个度量d=0使用输入[0,2047]，此后每接受4点产生d+4；度量坐标按实际有效输出计数。平台至少4个度量、最多1024个（4096样点）；上限是新捕获容量域，超长显式拒绝。平台中点d减半CP256，向下4点对齐得到候选锚点，再用原有限窗粗核和精核确认；有效精TO才生成rx_frame_id。

连续历史8192点（2048x128=32KiB），双snapshot各1024beat物理深度，总32KiB；各slot有效使用794beat=3176点，余量不包含未知填充输入。局部最老所需地址anchor-256，最后anchor+2919。复制前确保最后点已接收，且最老年龄+3200<8192；3200覆盖794次请求的3176个新输入及6拍余量。每次实际读另查未过期/未读未来。历史不为35569/65024拍精估计等待保留，全速复制后转移租约到snapshot。

两个snapshot slot由候选编号排序，单复制器并行读历史/写snapshot，单worker读snapshot/驱动原核心；结果单条稳定保持，ready低可无限保持（有界输入候选可能显式drop）。候选到达复制忙/slot满会递增capture_drop_count；服务后确认位置4096点内的已排队候选去重。初版检测密度/突发容量有界，不承诺不可反压ADC持续资格。所有计数为当前epoch；gap/session边界清空历史、候选、在途结果，epoch递增。valid空拍不改变相邻样点关系。

测试输入60324点，4例正式单径波形（TO=-101,-101,0,+101，CFO=-150k,0,+150k,-150k），真实落点lane0/1/2/3。未知前置/随机噪声、非PS1重复序列假候选、前导跨256beat加载块。块间固定8000拍回放停顿，4帧不复位。被动checker独立接收truth文件，源驱动只读stream及长度，DUT无truth接口。checker从实际握手流独立重算每个S&C度量，核原阈值、精TO零点误差、CFO≤1000Hz、内部编号0..3和结果128拍背压稳定性。尾部检查采集中断/中止/重启/复位。测试不覆盖任意信道、无限候选、不可反压全时满载和NI平台。

SF002本包只跑这一新联合行为门，不重跑SF001和历史91例，不综合。行为通过后立即转向同一产品top FLGB综合/实现/CLIP。任何新算法数值失败保留首个坐标和现场，回交Astra；Luna不能改DUT/checker/真值门槛。
