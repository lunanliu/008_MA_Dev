# 同步前端架构与分阶段冻结

本工程实现未同步原始流的自主接收。2026-09-14首包SF001是正式算术迁移及可打开工程基座；尚未实现/验收自主捕获，不可作为CLIP发布。

## 外部合同

125MHz单时钟，4复数/拍，逻辑Fs=500MS/s。data[32*k+:32]={Q16,I16}，lane0时间最早。输入仅clk、同步释放复位、session_start/session_abort、stream_gap、s_valid/s_ready、s_data[127:0]。每次握手接受4个样点，内部64位绝对计数加4。加载块边界不复位计数和检测器。没有frame_id、frame_start或真实起点输入。

valid空拍表示回放暂停，后续样点仍相邻；stream_gap表示物理采样丢失，终止当前候选并推进采集代次，重新预热。不可反压源必须始终采样；若无法接受，记录overrun及采集断裂，禁止把丢失区间拼成连续样点。第一版完整beat，尾部不足4点由传输端合并；不能把补零作为真实样点。

输出valid/ready稳定保持整条记录：epoch、内部rx_frame_id、candidate_id、64位绝对粗/精TO、带符号CFO_Hz、quality、status及缓存租约。内部编号仅在有效精TO确认后增加。无效候选有独立计数/诊断，不冒充有效帧。原始数据保持未做全帧CFO补偿；下游使用同一epoch与绝对位置关联其采集缓存。

## 数据流和必要控制变化

1. 连续原始历史环：在检测前写入；按实际接受样点维护地址及代次。
2. 连续S&C检测：1024样点延迟、4lane复乘/能量聚合、1024点滑窗、既有阈值算术。复用正式coarse_corr_energy_4lane/coarse_metric_threshold官方IP及位宽；新增连续lag和滚动控制，不能继续依赖有限窗的index0/512-beat计数。保留最短平台、低能量及多峰拒绝边界。
3. 候选确认/去重：以滑动度量产生候选，保存平台边界和绝对坐标。候选关闭后冻结局部回放锚点；原有限窗粗核重新确认，精核原样接同一candidate的TO/CFO。精TO不支持或多峰则拒绝并重新捕获，不能锁死后续帧。
4. 局部回放：真实历史[-256,2919]，完整3176点连续794拍，不允许把外部valid空隙送进原粗核观察窗。锚点4点对齐，精TO恢复lane内位置；锚点绝不由checker提供。局部标签由适配器生成，仅为旧核私有合同。
5. 精估计服务及结果队列：同帧粗TO/CFO join、局部CFO旋转、精相关搜索。一次服务的deadline沿用65024拍，slot持有直到捕获数据已转移且结果/拒绝完成。新结果只能原子入队，ready低时所有字段保持。

旧T04平台中点到绝对位置的公式须以滑窗首样点推导并由逐点metric checker验证；不能把原9位metric_index溢出当成连续坐标。新捕获门新增后的未知前置/噪声/假候选适用域另行实测，不继承原91例的自主捕获PASS。

## 缓存生命周期与带宽

拟定连续历史8192样点=32KiB，写口每拍128bit、读口每拍128bit，均125MHz（单方向2GB/s）。两份待处理局部快照各3176样点=12704byte，共25408byte；活跃精核仍使用自己的既有局部缓存，释放后复用。总量不是整帧缓存之和。

连续历史只承担检测及快照复制；不因65024拍精估计耗时把整个环固定。一次快照794拍，与写入独立端口并行。安全条件为：复制开始时最老所需样点年龄+复制期间新写入样点数+读流水余量 <8192。冻结实际检测最大延迟后计算并断言；目前32KiB为候选设计值，未宣称容量已验证。排队候选必须已复制到独立slot，禁止把一个裸地址在环中等待65024拍。未能及时复制/队列满/代次变化均显式拒绝，记录峰值、占用及丢弃原因。

两份snapshot不是无限突发资格。持续通过门需测accepted samples/cycles、最大service gap、无丢/重/乱序、候选速率和FIFO峰值。4x125MHz仅是接口峰值。原完整帧334080拍间隔可作为一个有界工作负载，不能作为硬件已合格结论。

## 时钟与下游

已选粗/精核及DDS/复乘均单clk；当前不需MMCM、500MHz时钟或CDC。NI须提供合格125MHz逻辑时钟；异步reset同步释放，异步控制只作为经握手同步的消息，不逐位同步多位配置。若NI接口异域，另增明确FIFO边界后验收。局部窗口不会保存整个后续SFO帧；T10连接必须由采集侧共享原始样点缓存按epoch/绝对位置读取，不能只凭接收帧编号假定坐标一致。
