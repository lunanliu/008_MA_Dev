# Agent 工具调用与版本使用指南

适用：本项目 MATLAB、Vivado 2021.1、XSim、辅助 Python，以及它们的工程整理和复核。2026-09-14 首版。用户最新指令优先；本指南不授予启动实验的权限。

## 开工先读这十条

1. 先读根目录 AGENTS.md 和[版本入口](README_ZH.md)，确定本轮允许的工作。最新范围见[独立工程迁移要求](T10_STANDALONE_MIGRATION_SCOPE_20260914_ZH.md)；指南和历史作业本身不授予启动权限。
2. 先选**一个有证据来源的完整版本**，再选顶层。禁止按同名文件、mtime、最大的实验编号或文件夹名 FINAL 自动选版；禁止在不同快照中逐文件挑“最新”。
3. 正式构建必须明确磁盘 `.xpr`、目标 part、硬件 top、仿真 top、源文件集、IP、约束和输入。当前旧包为 FLGC；NI 目标是 `xcvu11p-flgb2104-2-e`，旧包不能改标签冒充迁移完成。
4. 通过 Vivado 项目管理源文件。Agent 可使用原生 Tcl，但必须对应同一 `.xpr` 的 GUI 操作；不得临时递归收集整个仓库 RTL 来拼顶层。
5. 运行前核对[文件锁定清单](source_lock.csv)。仅检查清单能发现已登记文件的缺失/变化；检查新增、遗漏或选错文件，必须另将**实际工程导出的文件集**与单一构建scope比较。不能拿登记清单自己与自己比较后声称实际工程合格；不得自动改清单使检查通过。身份一致不等于功能/时序验收。
6. 明确解释器和软件版本。不能在 Vivado 环境里直接调用裸 `python`，不能修改 Vivado 内置 Python；不要为局部调用错误修改系统 PATH、PYTHONHOME、PYTHONPATH、TEMP。
7. 先用最小真实工具流程验证启动、文件加载、错误输出、正常结束和取消，再做长任务。普通脚本语法检查不证明 XSim 接受相同命令。
8. 测试台先核对输入长度、首尾值、未知态和配置，再送入 DUT。第一处数值或握手错误立即记录时间、帧号、采样编号、实际值与预期值，停止该失败实验。
9. 分开记录**进程存活、仿真时刻、算法进展、结果验收**。CPU忙、上次事件时间、exit 0、结果文件存在，都不能互相替代。
10. 保存已成功阶段。日志汇总、展示或消息交接失败只重做相应环节；不得因此重新综合或重跑已通过的仿真。新作业仍须遵守原 Astra/Luna 配对、资源预算、硬超时和工作期间15分钟报告。

## 固定工具边界

推荐执行关系：离线 MATLAB/数据准备 → Vivado 项目及原生 Tcl → XSim＋SystemVerilog 测试台 → 原生结果 → 离线数值复核。

| 层 | 应负责 | 避免 |
|---|---|---|
| MATLAB | 黄金/定点模型、波形和参考答案；单独运行并完整发布数据 | 在既有文件驱动 RTL 仿真中临时加入在线 MATLAB 依赖 |
| Python | 离线转换、哈希、数值比较；必要的独立进程监管 | 多层嵌套启动、通过反复全文解析日志控制每段仿真 |
| PowerShell | 明确工具路径和本次环境，启动、等待、归档 | PowerShell/cmd/Tcl 多次拼接同一命令字符串 |
| Vivado Tcl | 固定工程、source set、top、生成/运行/报告命令 | 把 Vivado 的命令直接假定为 XSim 支持 |
| 测试台 | 时钟、复位、输入、握手、计数、逐点检查和明确完成信号 | 未成功读入参考文件就运行 DUT；用参考答案驱动应由 RTL 估计的结果 |
| 监控 | 本次所属进程树、资源、硬超时、最近真实进度 | 把可选状态副本写入失败直接升级为终止计算 |
| JSON/CSV | 少量配置或记录，单写者，清楚字段含义 | 为每次修复增加一套状态系统；把格式正确当成内容正确 |

### 并行计算与资源

2026-09-14最新要求：后续Vivado general/synth线程请求均8，必须经项目run的PRE钩子传入子进程并回读，不能只改父GUI。jobs及xelab子编译默认/上限16；实际值按当前内存与各子作业峰值选择，资源不足可降低并记录原因。MATLAB新启动不带 `-singleCompThread`，使用自动计算线程；串行槽不等于单CPU线程，不自动开并行池。历史冻结入口保留，仅新执行入口采用这些参数。不得为参数核对重跑完整实验。独立工程的统一入口与细则在 `D:/008_MA_Dev/tools/vivado/configure_parallel_jobs.tcl` 和 `D:/008_MA_Dev/docs/TOOL_PERFORMANCE_ZH.md`。

### Python 与环境

- 2026-09-14 实测系统默认 Python 为3.14.7，近期监管器为独立3.12.14；当前全局和用户级 PYTHONHOME/PYTHONPATH/PYTHONUSERBASE 均未设置。这是审计快照，不是要求用户改成某版本。
- 项目后续选择经过验证的独立环境并固定依赖；调用记录须包含解释器完整路径及版本。新工程不得把个人 `.codex/.cache` 路径写成其他机器必须具有的依赖。
- 从 Vivado/XSim 子进程调用项目 Python 时，为这一次子调用隔离 `PYTHONHOME`、`PYTHONPATH`、`PYTHONUSERBASE` 等影响；使用适当的 `-I -X utf8`。不要破坏 Vivado 自己的环境；必要时调用后恢复。
- `-I`会影响导入路径，不能假定项目旁边的模块仍可直接 import。应安装项目依赖/包或使用明确的单文件工具，并验证同一启动方式。不要用新增全局路径修补它。
- 两个 Python 都能启动不意味着其第三方库完全一致。数据转换前检查所需 NumPy/h5py 等版本；纯身份核查工具仅用标准库。

### 路径与文件

- 保留旧根目录。新工程建议短、本地、可写、无空格的路径作为降低复杂度的措施；正确传参仍必须支持空格。禁止直接搬动旧冻结包、建立链接冒充独立副本。
- 本次审计复现：263字符的旧快照路径普通读取报WinError 3，使用Windows扩展路径可以读取；共18条路径通过扩展路径读取恢复。先区分路径长度和真正缺失，不能据此删除或重生成旧证据。不要假定所有EDA工具支持同一种长路径处理。
- 参数按工具所需形式作为独立参数传递；Tcl优先 `file join`、`list` 和规范化路径，避免原始 Windows 反斜杠被再次解释。
- 固定工程工作目录，数据路径由工程根解析。`$readmemh`遇错先检查最终传入字符串及XSim工作目录，不先修改滤波器或缓存。
- 本地和远程各有独立 `.runs/.sim`、IP生成目录及日志；不共同写同步目录或一份活动工程。源码/参数相同不等于可以共享可写缓存。
- 迁移后先由实际执行任务在目标输出目录小写入并读回；其它任务的完全访问不自动传递。写入失败先查该任务有效权限，不反复生成长脚本。Vivado属性值以连字符开头时，优先用 `set_property -dict [list ...]`；Tcl花括号不保证消除工具选项歧义。
- 临时工作区只负责可重建产物，发布结果在稳定目录。运行中不复制未写完的日志/WDB/DCP当作完整结果。

### 结果、监控与故障分级

- 日志读取需明确的完整记录/结束边界；“文件大小暂时不变”不证明写完。读取JSONL时忽略尚未结束的末行，不能把半条记录当成损坏整个作业。
- 指定单写者。必要的原始记录和可选状态展示分开；可选副本遇短暂共享冲突可限次重试并报告降级。硬超时、内存预算、取消指令、根本性RTL错误仍必须生效。
- 保存 traceback、失败操作、源/目标路径、时间及所属进程信息。缺证据时写“占用者未确定”，不能断言杀毒或某人打开文件导致。
- Windows权限允许访问，不表示其他句柄允许替换文件。启动前的沙箱ACL错误、运行中的文件共享冲突和应用审查拒绝，按不同故障处理。
- 监管的本次进程树归零与根进程退出码分别确认。不能按名称批量kill，不能把脚本退出或已知PID消失当作全树退出。
- 进度至少包含模拟时刻、算法阶段、已接受输入/输出数、阶段墙钟耗时。最近算法事件只能叫“最后事件”，不能叫“当前仿真时间”。不按CPU利用率承诺结束时间。
- 取消、错误结束、成功结束采用相同可追溯收尾原则；不能将缺少完成证据归类为PASS。纯仿真编译快照不保存中断时动态状态，不能假称断点续跑。

## 遇到旧故障，按这个顺序处理

| 现象 | 首先检查 | 禁止的草率处理 |
|---|---|---|
| `SRE module mismatch` | 解释器路径及其继承的Python库路径 | 升级/重装全机Python；改全局PYTHONHOME |
| `invalid command name redirect` | 当前是Vivado Tcl还是XSim Tcl，实际命令是否可用 | 只验证Tcl语法后继续长任务 |
| 文件存在但加载失败 | 最终文件名、参数边界、工作目录、输入未知态 | 先把错误归因于DUT运算 |
| 在线日志条数少于结束日志 | 刷新、读取边界、末行完整性 | 固定sleep后假定完整；屏蔽后出现的错误 |
| 转义实例名匹配失败 | SV转义标识符与层级名称的解析规则 | 直接忽略所有同编号XPM错误 |
| 状态文件PermissionError | 哪次读/写/replace失败、是否共享冲突 | 扩大整盘权限；因展示文件失败终止可靠运行 |
| 报告或交接失败 | 原生阶段是否已成功、产物是否完整 | 重做成功计算来获得新通知 |
| 多个同名源码 | 版本表、锁定清单、实际source set | 按最新时间挑一个，或全部加入工程 |

普通执行故障由本任务Luna自修；改变RTL/算法/输入含义/验收条件、重大卡死或设计问题才反馈Astra。不得用本指南绕过用户暂停。

派发即冻结，不能因界面暂未显示启动就原地改输入；修复另存新文件名和指纹，以launch及原生日志核对实际版本。未确认存在的 `redirect` 不可作入口依赖，普通帮助直接输出到原生日志。

## 首次使用或修改工具入口时的检查

用一个有预算的小检查覆盖：打开同一工程 → 编译/展开 → 成功加载数据 → 短仿真及首错定位 → 正常结束 → 取消及全进程树收尾 → 报告读取。检查本身须在用户授权范围内；本指南的编写和静态自检不表示已完成这些native步骤。

运行入口、解释器、路径传递或监控逻辑变化后，只重复受影响的短检查。版本核查脚本通过，只证明身份；不自动恢复实验、不允许旧FLGC产物充当FLGB产物。
